Architecture & Roles

Three Distinct Management Portals

Admin Portal

Central control hub for institution governance, financial workflows, and registrations.

  • Approve & manage teacher accounts
  • Review student admissions & details
  • Broadcast campus-wide notices
  • Track student fee payments & balances
  • Monitor staff salary disbursements

Teacher Portal

Dedicated dashboard for faculty members to record attendance and stay updated on announcements.

  • Quick daily attendance recording
  • View attendance records by date & class
  • Access official administration notices
  • Track personal payroll & salary status
  • Profile & credential updates

Student Portal

Self-service portal for enrolled learners to monitor academic standing and attendance.

  • View individual attendance history
  • Instant fee invoice & payment status check
  • Read campus notice boards in real-time
  • Direct contact submission with administration
  • Profile information management

Deployment & Local Run

Quickstart Instructions

To run the dynamic Django server with database on your local machine:

# 1. Clone the repository
git clone https://github.com/daggavoluganesh/school-management-system.git
# 2. Enter directory and install requirements
cd school-management-system
pip install -r requirements.txt
# 3. Apply database migrations
python manage.py migrate
# 4. Start the development server
python manage.py runserver
# Visit http://127.0.0.1:8000 in your browser!
